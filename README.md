# GuixSoftArt Web Tools

A collection of simple, free and open-source browser tools.

## Features

### Text Analyzer
Analyze text instantly and see:

- Character count
- Word count
- Line count

### Password Generator
Generate secure random passwords directly in the browser.

The generator uses the browser's Web Crypto API and does not send passwords to a server.

### Color Generator
Choose a color and obtain its HEX value. You can also copy the color code to the clipboard.

## Privacy

The tools run entirely in the user's browser.

No account is required and the project does not need a backend server to operate.

No text, generated passwords or selected colors are sent to an external service.

## Technologies

- HTML5
- CSS3
- JavaScript
- Web Crypto API

No external libraries or frameworks are required.
